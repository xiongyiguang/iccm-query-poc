## 入口与环境

Python 3.11+，应用使用标准库。常规自然语言问答需现有DeepSeek凭据与网络。macOS双击根目录`打开演示.command`；其他环境按[运行手册](docs/07-部署与运维/监控与运行手册.md)配置后运行`python3 backend/app.py --port 8765`，浏览器访问http://127.0.0.1:8765/。腾讯云普通版经既有代理公开，地址http://106.53.130.181:8899/，需要既有演示账号。

`agent_demo/启动智能体.command`及`agent_demo/server.py`命令入口只提示已停用，不启动监听或调用Codex。个人Codex安装、登录及账户配置不属于本轮变更。
