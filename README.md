# iCCM 智能问数 POC

2026-10-09发布候选：本次仅发布DeepSeek普通版公共机制修复，活跃协议V32/V28/V25、业务请求V10/独立清单V13；Codex智能体保留已提交交接版本。发布状态和本轮实测以[普通版r12发布记录](docs/07-部署与运维/DeepSeek普通版r12发布记录-20261009.md)为准；下文旧日期的“未发布”及r11表述为历史事实，不代表本轮最终状态。

基于五类脱敏 CSV 的设备数据问答原型。普通版使用 DeepSeek 生成受约束请求，Python/SQLite 执行关系查询、筛选与统计并返回原始行依据；本机智能体使用 Codex App Server 调用同一只读数据执行层。行业知识 RAG 暂缓，未建设向量知识库。

普通版已准备第三轮及公共机制扩展修复，发布以r12记录为准；本机Agent交接代码保持原版本，后续智能体修复不在本次提交或腾讯云部署范围。

## 环境和入口

需要 Python 3.11+；应用使用标准库，无应用级 Python 第三方依赖。离线测试需另行取得对应的已授权数据。普通自然语言问答需要 DeepSeek 凭据及网络；Agent需要已登录的本机Codex运行时及网络。

|入口|启动方式|浏览器地址|当前用途|
|---|---|---|---|
|普通版本机|macOS双击根目录 `打开演示.command`；其他环境按运行手册配置后运行 `python3 backend/app.py --port 8765`|http://127.0.0.1:8765/|受约束规划、确定性执行|
|本机智能体|macOS双击 `agent_demo/启动智能体.command`；或 `python3 agent_demo/server.py --port 8771`|http://127.0.0.1:8771/|自主只读工具调用，独立会话|
|腾讯云普通版|密码保护演示，本轮普通版r12发布|http://106.53.130.181:8899/|r12发布状态见本轮记录|

服务仅绑定回环。腾讯云通过既有反向代理公开普通版；本机Agent未部署腾讯云。账号、密码、API密钥及登录材料不在仓库。

## 仓库与数据

```
backend/       普通服务、请求契约、模型、数据与查询执行
frontend/      普通问数及导入、登录界面
agent_demo/    Codex适配、工具、结果解释、独立页面与测试
prompts/system/ 版本化模型提示词及计划schema
tests/         离线契约测试、真实模型/页面回放脚本
scripts/       macOS入口与历史PowerShell工程工具
docs/          当前设计、运行、测试和历史记录
```

默认种子数据必须放在仓库上一级 `中广核iCCM项目智能问数DEMO脱敏数据/`，文件为 `pbs.csv`、`构型树.csv`、`设备类.csv`、`部件类.csv`、`测量点数据分析.csv`。CSV不随源码推送；只克隆仓库不能恢复客户数据、导入状态或模型凭据。数据来源与恢复细节见运行手册。

`.local/`、`inputs/`实际导入快照、`docs/.staging/`中原始验证输出、依赖缓存和客户原始Word/CSV不提交。GitHub仓库已按用户要求公开。源码和工程文档包含脱敏示例编码及技术查询口径；本机资料、凭据和指定不公开的文档不随仓库发布。

```sh
node tests/test_frontend_runtime.cjs
```

本轮实际结果以交接核验记录为准。上述离线测试不调用真实模型，不等于第三轮问题关闭；真实回放脚本需单独读懂目标、凭据、费用和输出位置后执行。研发执行规则见 [AGENTS.md](AGENTS.md)。
