# 测试与验收 Prompt

按 AGENTS.md 与 docs/00-项目治理/分级执行与裁剪规则.md 的入口路由执行；读取 PROJECT.yaml、索引相关条目及本轮真正相关的已确认事实和设计来源，排除 .staging。阶段门禁通过后持续完成已授权请求，仅读请求保持只读；不因阶段切换重复确认。


明确本轮对象、环境、版本和冻结预期，按当前影响与风险执行功能、异常、边界、权限和相关旧能力回归；性能、容量、部署及 AI 评测仅按实际适用性启用。配置型产品按已冻结异构场景验证复用。

将相关 SCN/REQ/AC/RULE 关联到测试、样本和具体证据。失败项按 docs/00-项目治理/系统性问题解决方法论.md 分级处理，保留原始失败，不更改冻结预期来通过测试；用户已要求修复时持续定位、修复并重新验证。关闭项均有结论，适用项提供必要证据，不适用项记录有依据的 N/A，不制造无价值证据。

界面按 docs/03-架构设计/前端交互与组件基线.md 中当前 ui.profile 进行实际界面验证，固定企业桌面矩阵仅 enterprise-web 启用。材料异构集、输出变体及留出集仅 semantic_extraction 或实际材料抽取启用时按语义治理执行。

登记真实结果和环境差异，未运行的适用项保留未验证；局部或结构检查不代替完整验收，最终验收由有权限人员给出结论。
