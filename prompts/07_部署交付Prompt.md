# 部署与交付 Prompt

按 AGENTS.md 与 docs/00-项目治理/分级执行与裁剪规则.md 的入口路由执行；读取 PROJECT.yaml、索引相关条目及本轮真正相关的已确认事实和设计来源，排除 .staging。阶段门禁通过后持续完成已授权请求，仅读请求保持只读；不因阶段切换重复确认。


Release 或本轮实际涉及部署运行时读取对应部署与回滚方案、监控与运行手册和发布检查表；普通 Startup/Iteration 不因文件存在就自动加载或确认。母版交付准备仍属于 TemplateMaintenance/TemplateRegression，不伪造业务 release_authorized。

业务 Release 检查当前范围的授权、验收、已安装/候选/目标版本和差异、制品完整性、配置密钥、依赖、恢复与运行证据，按三个运维唯一源执行。仅登记实际存在的数据库、模型、Prompt 和知识库版本。无服务部署时说明本地运行、停用/恢复和交付方式。

输出可发布性、步骤、失败停止条件、已知限制和人工事项。未获用户明确授权不实际部署、发布、发送通知或修改外部系统；已有授权覆盖的步骤继续执行，结构与真实运行验证分别陈述。
