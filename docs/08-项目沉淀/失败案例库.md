# 失败案例库

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

本文件维护失败模式与证据入口，完整问句和状态见对应原始反馈及冻结脚本。失败记录保留，不因后来局部通过删除。

|失败模式|影响|证据入口|当前状态|
|---|---|---|---|
|对象与类别、同码跨树混用|错误主体/名称/统计口径|两轮逐项复测、对象范围契约|曾修正，仍需自由问法验证|
|新主体被旧主体覆盖|查错对象却返回合理数值|r11直接查询专项、第三轮域切换|r11有限修复通过，新反例开放|
|数值条件/单位来源丢失|条件不完整或猜单位|独立条件清单、单位/边界冻结测试|部分机制已验证，不保证普遍正确|
|澄清短答未收敛|用户反复补答仍未完成|第三轮第1/3/4组|待分析，暂停修复|
|输出动作退化为列表|“最高”得到全部报警记录|第三轮第4组|待分析|
|口语字段与明确字段不一致|同义问法一拒一成|第三轮第6组|待分析|
|能力入口/按钮与对象不一致|可见功能无法完成|第三轮第5/7组|待核验|
|合法零结果被误认为失败|名称/编码口径误读|第三轮TMP及CSV核对|需查看实际查询依据，不能自动判子串不支持|
|缺数据被当作可计算|虚构时长或设备判断|duration历史修复、第三轮时长图|缺数据边界保留，不新增数据|

分析应寻找共享契约与状态原因，不叠加单问句规则；真正修复后按原问句、代表变体和上下游验证，再明确可关闭范围。
