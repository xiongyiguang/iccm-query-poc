# 母版 2.8.0 升级说明

日期：2026-09-13。定位为软件开发项目工程母版；保持 is_template=true、未初始化，不包含客户业务数据。授权来源：本轮用户明确要求的十五项定向重构与持续修复验证。

## 问题、范围与六问

- 类别：规则多源漂移、入口与能力作用域混淆，属于公共契约的系统性问题。
- 不变量：已授权工作持续完成；必要控制随风险与影响启用；母版完整性不等于业务项目启用全部模块。
- 共同机制：根规范、Prompt、专项表格重复规则，完整结构检查与业务门禁耦合。
- 公共责任层：入口路由、专项唯一源、readiness 与模板回归职责。
- 通用规则：身份/入口/影响/profile 分开决定；缺陷按风险分级；局部规则只补充明确作用域。
- 矩阵：保留 2.7 的 55 个场景预期，新增无可选模板业务项目、前后端、AI/RAG、局部迭代、发布拒绝、局部规范、UI profile 与历史隔离等正反案例。

## 兼容与历史

PROJECT.yaml 保持 schema_version=3，新增可选 ui.profile；本轮变更 schema_version=1 新增可选 affected_modules，旧记录从 impacted_gates 推导最低依赖。旧前端项目缺 profile 时只按通用规则并提示登记，原冻结验收不降低。Development 保留完整设计评审兼容入口。Structure 现在只检查基础登记，不再证明完整母版；完整性使用 Test-TemplateRegression.ps1 -StructureOnly。

母版入口 Audit 不写记录、不初始化；TemplateMaintenance 使用本说明记录维护；TemplateRegression 使用隔离合成项目。业务 Startup/Iteration/Release 保留相应证据和安全门禁。旧项目按需迁移，不整体覆盖、自动生成确认或改写历史基线。

修改前唯一源快照：docs/.staging/v2.8.0-validation/before/。这是明确的历史快照，不是第二份维护源。2.6/2.7 证据按文件哈希核对保持不变；回退须逐文件比较并恢复，保留新增文件，不删除目录或批量清理。

## 规则结构与检查器变化

AGENTS 改为根入口与路由；分级规则管理身份、入口、风险与按需加载；缺陷方法论保留完整六问和十二项关闭，并增加简单局部、一般功能、系统性/高风险三级处理。所有关闭项都有结论，适用项有必要证据，N/A 有影响依据，可合并记录，不制造无价值证据。

前端基线分通用 UI 与 enterprise-web 细则。frontend-design 仅为可选外部能力，未复制技能或绑定本机路径。语义抽取专项仅实际启用时强制，通用 Prompt 保留功能、契约、版本及相关回归。README、阶段 Prompt、测试方案/案例、失败库不再复制完整六问、关闭清单、企业 UI 或抽取治理正文；复用要求引用现成方案调研唯一源。

TemplateRegression 负责 70 个模板文件与 11 个目录的完整性，含全部可选模块；ProjectReadiness 保留基础安全与身份检查，按入口和 affected_modules/impacted_gates 选择当前适用文档与门禁。Iteration 复用未变化模块状态，部署相关迭代核对运行恢复来源，Release 保留完整发布授权、严格复核、回滚、证据路径和 Git 状态检查。无 AI/RAG/Agent/智能审核等可选目录的业务项目可通过相应门禁，真正启用但缺设计的能力仍被拒绝。

子级 AGENTS 允许明确目录 scope 和 supplemental 声明，禁止另立全局规范或完整复制根规范；历史区在当前规则遍历时被排除。索引移除无法持续维护的“最后更新”要求，版本及状态字段保留。

## 已知限制与结论边界

- 合成测试证明登记路由与拒绝行为，不证明实际用户授权、业务设计正确性、UI 可用性或现场产品验收。母版没有业务界面，本次未宣称真实产品浏览器验收。
- 影响范围、能力启停的准确登记与子级自然语言冲突仍需 AI/人员基于事实审查；检查器不能靠关键词推断真实业务，也不能从一个空数组证明无影响。
- YAML 读取保持既有受限格式，不新增通用解析依赖；schema_version=3 的两空格标量格式保持兼容。
- Development 兼容入口与历史文档中仍可出现旧版本描述；它们有明确的兼容/历史边界，不作为默认开发入口。
- 新旧文件通过快照和完整差异比较；当前母版按约定未初始化 Git，不存在本轮 Git 提交。旧项目迁移必须逐项核对，不能整体覆盖。

## 关闭项结论

本轮属系统性规则契约修复。方法论关闭项 1–5 由前述六问、公共路由实现和差异复核支持；6 由入口、模块、UI profile 和作用域显式契约支持；7–10 由双 PowerShell 宿主的原失败重测、正反矩阵、55 场景历史回归、入口到日志/结果完整调用链支持（环境限本机 Windows 合成登记）。11 由修改前快照和历史哈希支持；12 由规则唯一源、依赖路由和新增反例支持，不声称杜绝所有未来缺陷。真实客户业务、生产数据迁移和产品 UI 属 N/A，依据是本期仅维护软件研发母版，无此类运行对象。
