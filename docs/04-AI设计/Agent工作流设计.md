# Agent工作流设计

版本：V5｜整理日期：2026-10-09｜用途：当前工程交接；非客户正式验收。

本模块仅适用于agent_demo本机独立入口，不适用于腾讯云普通版。完整历史实现和实测唯一记录见[本机Codex智能体演示](../05-专项设计/本机Codex智能体演示.md)，本文件维护责任与调用流程；当前V12关联修复唯一源见[公共机制修复](../05-专项设计/Codex智能体公共机制修复-20261008.md)。

创建会话时，runtime启动官方已安装App Server，检查登录，注册动态只读工具并设置read-only沙箱、禁用终端/文件/网页/外部应用。基础知识进入baseInstructions；新会话默认Sol/low，已有会话模型不随下拉选择变化。

用户提交后先生成真实准备事件，再启动turn。模型说明查询思路、自主选择工具；DataTools读取同类数据层，校验对象、来源和范围。工具开始展示待执行理解，成功后依据实际回执更新业务口径，最终事实答案由answers.receipt_answer产生。未经执行的模型草稿不改写数值。

|文件|职责|
|---|---|
|server.py|会话、turn通知、工具事件、停止和三分钟演示时限|
|runtime.py|JSONL请求/响应、动态工具回调、连接失败、登录检查|
|tools.py|iccm_catalog/lookup/query/attributes/children/explain/clarify等只读适配|
|relational_protocol.py|受限关系接入、稳定整数任务、已执行角色身份、原字段投影及部分交付|
|request_protocol.py|完整目标、独立PBS父范围、原话增量与公共任务编译/分支提交|
|protocol_diagnostics.py|同一公开Schema的入口校验、错误字段路径与空任务编号兼容审计|
|bindings.py|邻接对象域限定及字面来源，不承担完整语言理解|
|knowledge.txt、query-guide.txt|业务概念与独立工具协议|
|completion-check.txt|没有完成目标的回执时最多一次完成核对|
|presentation.py、answers.py|待执行与已执行口径、实际回执最终答复|
|web/app.js|事件轮询、可展开过程、多对话、停止及分页|

最多20个内存对话，每轮最多12次工具调用。新建会话失败释放预留容量；等待运行时响应不能持有通知锁。目录读取不是业务完成，候选不是已选对象，失败或未匹配不能沿用旧成功焦点。

当前无持久Agent对话或自动写回。模型在线推理会接收必要脱敏回执，不能称完全离线；完整结果尚未满足五秒目标。历史交接只中文化注释；本轮已改变工具契约、知识与本机新会话默认模型，GitHub交接副本及腾讯云仍保持原版本。


直接查询优先iccm_request，更新按稳定任务/筛选ID保留未改项。单轮开始冻结前状态，失败重试不采用失败尝试的状态；独立成功分支与待补分支分别交付。七字段结果目标由公共执行器计算，目录/定位/翻页不单独证明计算完成。跨表关系与完整分类/类型/来源/位置分组使用iccm_relational，直接筛选及计算继续使用iccm_request。

V6.1每项明确parent_range：全表all_imported、沿用inherit或有据PBS根。根与测点自身筛选分别编译，根范围只覆盖自身及全部后代关联测点；解析失败保留待补，不查全表。缺域介绍仅展示有原行证据的精确候选，保留pending domain及目标。任务sources是范围唯一状态，task_directory仅作投影。

动态工具Schema同时用于入口校验，错误指出字段路径。search允许空属性清单，attributes仍须实际属性。只兼容任务层不携带任何条件编号的ids=[]，记录protocol_adjustments；非空编号和其他错层字段不丢弃。102项Agent离线及608项普通共享回归通过；真实模型完整成绩与各轮失败只登记在[缺口修复验证](../06-测试与验收/Codex智能体缺口修复验证-20261008.md)。
