# 模型与评测设计

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

普通问数与本机Agent独立评测。模型负责自然语言和计划，程序承担事实、关系、计算和证据；两模型一致不等于正确性证明。

|能力|配置事实|输入与输出|限制|
|---|---|---|---|
|普通主语义|DEEPSEEK_MODEL默认deepseek-v4-flash，thinking disabled|问题、必要上下文、业务目录、引用→结构化路由及请求|部分旧路径还有计划生成或统计复核|
|独立完整条件清单|ICCM_CHECKLIST_MODEL默认deepseek-v4-pro，thinking默认disabled|原话与本轮前状态→完整类型化条件|不接收候选计划；核验分歧仍可能误解|
|有限端点复核|ICCM_ENDPOINT_REVIEW默认0|已定义边界分歧→已有请求之一|实验分支，不默认启用|
|本机智能体|默认gpt-6-luna/low，可选Sol/Astra|问题、概念、工具协议和必要回执→自主只读工具调用|App Server实验接口；未部署腾讯云|

当前普通Prompt入口为query-intent-v26及schema、context-scope-v22、request-checklist-v18；旧Prompt留存，不是全部都在运行。资产唯一登记见Prompt资产管理，实际路径以backend/model.py和request_checklist.py常量为准。

## 评测方法

先冻结原问题、前文、显式选择和独立CSV预期，记录代码或文件清单哈希、Prompt、模型实际响应标识、参数、数据版本与环境。不能从同一执行器产生预期再证明执行器正确；原始行与父链独立遍历用于对象集合和数量核对。

每轮判定是否完成所问输出，不仅看status。名称、条件、单位、范围、分组或排名、完整集合及来源均须一致。可回答请求被无效澄清或拒绝不能算通过；真正不支持及缺数据另外登记。单轮和整段分别记录。

时延分别记录首个处理反馈、模型思路、服务端完整结果和浏览器完整可交互呈现。修复、重试、失败、超过5秒都保留；报告样本数、中位、P95和最大值，不能把单题排名推广为稳定模型排行。
