# 测试方案

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

测试分为结构等价核验、离线组件/HTTP回归、真实模型回放和实际浏览器业务验证。不同层结论不能替代：注释改写后结构相同不能证明已知语义Bug解决，离线Mock成功不能证明真实模型正确，HTTP计时不能证明浏览器完整五秒。

|层级|检查对象|执行方式|适用范围|
|---|---|---|---|
|注释等价|Python可执行AST；其他脚本去说明注释后的正文|对比本轮before快照|本次中文化；保留标识、Prompt、测试预期|
|离线后端|查询、属性、关系、条件、单位、状态、导入、认证、HTTP契约|unittest discover tests/test_*.py|授权CSV及临时本机端口，真实模型调用被隔离|
|离线Agent|只读工具、回执答案、知识、展示、过程和会话锁|unittest discover agent_demo/test_*.py|不启动真实Codex或网络模型|
|前端运行|请求初始化、事件和新会话等|node tests/test_frontend_runtime.cjs|合成DOM，不代表视觉验收|
|真实语义|原反馈、多轮、留出、单位和任务等|读取对应replay脚本后运行|使用在线模型/额度，需单独安排；不是默认批量运行|
|浏览器|登录、输入、补答、对象、分页、证据、历史和快捷入口|现有浏览器脚本/实际操作|部分脚本有旧绝对路径，先适配团队环境|

运行入口见07运行手册。本轮只改说明性注释和文档，完成必要离线回归，不调用真实模型重跑第三轮，也不修改云端。实际执行结果集中写入[交接核验记录](交接核验记录-20261008.md)，未执行项明确记录。

真实模型测试先冻结代码、数据、Prompt、问句和原始行预期，逐轮及整段判定。不删失败、不修改冻结问句来通过；勘误须保留原记录并说明依据。业务支持请求被拒绝或无效澄清仍是失败。

原5秒目标从用户提交到答案、总数和首屏表格可交互，不以首字或准备事件替代。需区分冷启动、会话创建、模型理解、查询、传输和渲染；报告完整样本而非只取快样本。并发、TLS、灾备和正式客户验收未完成。
