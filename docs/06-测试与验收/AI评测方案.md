# AI评测方案

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

评测任务不是模型通用跑分，而是当前五表问数的完整语义理解与执行结果。入口、数据和参数冻结后，依次执行原反馈回归、未调试的留出表达、多轮状态反例和界面真实操作。

|指标|定义与报告方式|
|---|---|
|任务正确性|主体、条件、单位、范围、输出动作、结果全集和依据均符合预期；报告逐轮和整段|
|需求完整性|最高、排序、取首项、全部阈值、比较和任务成员不遗漏；拒绝合法请求算失败|
|状态正确性|新题/续改/保留、点选对象、待补草稿和已执行事实不串线|
|证据一致性|独立原CSV计算预期，不使用同一执行器产生真值；分页不改变总数|
|时延|服务端和浏览器完整结果分开，含修复/失败；报告样本数、中位/P95/最大和超5秒条数|
|失败可解释性|空结果、未查、缺数据、不支持、计划错误和模型不可用分开|

主/独立模型对同一原话可能共错，因此两者一致不能单独计为正确。历史回放经调试后是回归集，不能继续宣称盲测。维护者编写的留出集与客户独立题集明确区分。Prompt/参数/数据改变后不得把旧通过率合入新版本。

真实模型和原始trace保留本地，有用量和数据传输；本次交接不新增在线调用。第三轮题作为下一阶段分析输入，尚未形成已运行的新准确率数据。
