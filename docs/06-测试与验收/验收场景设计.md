# 验收场景设计

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

验收应围绕真实对象和完整任务，保留提问、补答、切域与最终结果的连续链路。只给推荐问句或单轮状态，会遗漏当前第三轮反例。

|场景族|正常与反例|判定|
|---|---|---|
|精确对象及分类|完整名称/编码、同码跨树、新旧主体及完整别名/前缀|主体与原话对应；歧义给真实候选|
|关系和口径|直接/全部、仅部件/全部对象、现场/构型类别|完整原始父链和计数口径一致|
|属性及单位|18档阈值、0/空值/科学计数、缺单位及明确单位|所问投影完成，原值保留、不猜单位|
|澄清续接|名称、全部、高低排序、PBS/构型/设备类、所有记录|每次补一个必要业务条件，最终完成原任务|
|输出动作|最高/最早、月份计数、两个对象差值|动作可执行则完成；不支持明确说明，不静默退化列表|
|历史及切换|独立新题、刷新恢复、取消、重启签名失效|不串会话，不把旧结果当新结果|
|界面入口|选择不同对象类型后逐个快捷按钮、分页及依据|可见入口与能力/数据匹配|
|数据不足和错误|事件时长缺数据、模型故障、结构无效、合法空结果|业务不足和系统失败分开，不伪造0|

正式题数、复杂度、并发与澄清耗时处理尚待确认，本文件是工程场景安排，不冒充客户已批准验收集。
