## 新环境恢复

克隆仓库并准备Python 3.11+。普通版及Agent使用Python标准库；浏览器自动验证另需Node/Playwright，应用日常运行不依赖Node。Mac启动脚本优先发现本机Codex配套Python，缺失时使用系统python3；其他电脑直接使用自己的Python，不复制原电脑绝对路径。

取得已授权的五份CSV，按下列结构放置，保持中文文件名：

```
工作目录/
  iCCM智能问数POC/          Git仓库
  中广核iCCM项目智能问数DEMO脱敏数据/
    pbs.csv
    构型树.csv
    设备类.csv
    部件类.csv
    测量点数据分析.csv
```

backend/data.py按仓库父目录寻找种子CSV；种子读取GB18030，不应重新保存为错误编码。当前种子快照70abf31549af：PBS16796、构型24025、设备类3748、部件类1631、测点记录12985。启动加载已有 `inputs/imports` 活动快照时，实际版本可能不同；以页面数据版本和 `/api/meta` 为准。原CSV、活动与历史导入快照需分别由资料持有人授权交付，源码仓库不包含它们。

配置DeepSeek密钥采用本机安全入口或环境变量，不在聊天或共享终端记录中粘贴。Mac根入口读取 `.local/deepseek-macos.key` 并注入 `DEEPSEEK_API_KEY`；其目录权限应为0700、密钥文件0600。该文件未配置时脚本会提示退出。跨平台直接运行时由环境安全注入同名变量即可。`.env.example`保留母版变量说明，应用不会自动读取 `.env`，其中AI_API_KEY不能替代DEEPSEEK_API_KEY。

Agent由agent_demo/runtime.py依次检查 `ICCM_CODEX_BIN`、PATH的codex、Mac已安装Codex/ChatGPT应用内运行时；已登录状态通过App Server核验。不能只复制登录文件或要求他人在聊天提供令牌。未安装、未登录或运行时协议不兼容时，先恢复官方本机环境再运行。

## 启动、复用与停止

|服务|入口|监听|停止方式|
|---|---|---|---|
|普通版本机|双击 `打开演示.command`，调用scripts/macos-demo.py；或环境已配后运行 `python3 backend/app.py --port 8765`|127.0.0.1:8765|前台运行按Ctrl+C；后台入口先核对 `.local/macos-server.pid` 对应完整命令行和端口后只停止该进程|
|Agent本机|双击 `agent_demo/启动智能体.command`；或 `python3 agent_demo/server.py --port 8771`|127.0.0.1:8771|在本演示前台终端Ctrl+C，结束其专属App Server|
|腾讯云普通版|既有iccm-8899服务与Nginx|内部18765、公网8899|按当次运维授权操作；本轮没有启停、发布或改配置|

启动前检查端口是否已有本项目服务，已正常运行时直接访问页面。关闭浏览器不停止服务。后台普通日志在 `.local/macos-server.log`；PID文件不能单独证明进程身份。不要使用“结束所有Python”或删除运行目录排错。重启会使内存会话、登录会话与历史续问签名失效，原CSV与持久导入不受正常重启影响。

Agent当前Python模块需停止明确的本演示进程后重新启动入口加载，刷新网页不能替代服务重启。本轮未重启既有8771；新代码的实际验收使用自建8785隔离实例，最终结果见[缺口修复验证](../06-测试与验收/Codex智能体缺口修复验证-20261008.md)。

## 当前配置

|配置|默认/用途|交接说明|
|---|---|---|
|DEEPSEEK_API_KEY|无默认|普通自然语言调用的凭据，不提交|
|DEEPSEEK_MODEL|deepseek-v4-flash|主语义；实际模型响应标识需单独记录|
|ICCM_REQUEST_ENGINE|contract|设legacy走旧入口，仅兼容/对照，不作为建议|
|ICCM_PARALLEL_CHECKLIST|1|已验证schema路径启动独立完整条件清单|
|ICCM_CHECKLIST_MODEL|deepseek-v4-pro|独立条件清单|
|ICCM_CHECKLIST_THINKING|disabled|独立清单思考参数|
|ICCM_CHECKLIST_EFFORT|调用位置不同，high/low|仅启用thinking时相关；以实际请求为准|
|ICCM_RECONCILE_THINKING|disabled|条件对齐请求|
|ICCM_ENDPOINT_REVIEW|0|实验端点复核默认关闭|
|ICCM_TYPED_ENTRY_RETRY|0|类型化入口补试默认关闭|
|ICCM_AUTH_REQUIRED|未设，只有1启用|腾讯云启用登录保护；不能误用于直接公网裸露服务|
|ICCM_AUTH_USER|iccm|已有演示账号标识|
|ICCM_AUTH_PASSWORD_HASH|无默认|PBKDF2配置，不提交或打印|
|ICCM_PUBLIC_ORIGIN|无默认|代理外部Origin；HTTPS值决定Cookie Secure属性|
|ICCM_CODEX_BIN|自动发现|本机Agent运行时覆盖路径|

主模型请求当前设置thinking disabled。Agent界面可选模型，当前本机源码默认gpt-6-sol、low；该默认来自相同代码真实117步对照，用户全局Codex配置不改；实际可用性取决于运行时和账户，不把页面选项当模型调用成功。普通版与Agent鉴权令牌、会话和分页缓存互不通用。

## 日常检查与诊断

先打开正确入口，确认数据快照、模型配置及登录状态。`/api/meta`返回sources、counts和version供核对，token只用于当前服务请求，不在共享日志暴露。model.available只代表密钥存在，不证明联网、额度或真实推理成功。

本轮不对腾讯云重新实测。必要的只读运维检查包括核对服务状态、current链接、部署目录、源码指纹与数据版本；查看服务环境文件时避免显示密钥与密码哈希。部署记录中的active/running只对应当时核验时间。

诊断先记录完整问题、连续轮次、选择对象、入口、时间、数据版本、代码/Prompt版本、模型与实际响应。普通版仅在授权诊断时提交trace=true，从语义路由、清单、最终契约、完整执行集合、展示投影逐层比较；不把trace日志公开。Agent查看真实工具调用、回执、补查和最终答案，不用模型草稿代替执行证据。

|现象|检查与处置|
|---|---|
|FileNotFoundError或缺种子|核对父目录及五个文件名、编码；索取有权交付的资料，不编造测试数据冒充原件|
|端口被占用|核对现有服务所属项目及命令行，复用或按授权停止明确进程|
|Failed to fetch|核对入口、登录、服务与代理，保留错误；不直接删除文件|
|模型不可用/超时|核对网络、有效凭据和额度；引导查询正常不能证明自然语言调用正常|
|403|刷新本服务meta令牌并核对Host/Origin，确认是否把Agent令牌传给普通版|
|401|重新登录；不要公开账号凭据|
|旧数据版本、分页或续问失效|核对导入/重启/20项结果缓存上限，重新查询并保留前序记录|
|无限澄清、列表代替极值、主体切换|保存完整链路，核对实际加载版本；当前本机修复与真实结果见智能体缺口修复验证，云端仍旧版本|
|无法回答报警时长|原数据缺开始/恢复事件；不能用测量时间替代|

## 测试与恢复边界

普通离线入口 `python3 -m unittest discover -s tests -p 'test_*.py'`；Agent离线入口 `python3 -m unittest discover -s agent_demo -p 'test_*.py'`；前端模拟运行 `node tests/test_frontend_runtime.cjs`。在仓库根运行并设置PYTHONDONTWRITEBYTECODE=1。测试说明见tests/README.md与agent_demo/README.md。真实回放/浏览器脚本不属于默认离线套件，可能调用计费模型、既有服务或指定云端，必须先核对目标和实际数据。

完整恢复需要源码、Prompt、原CSV、持久导入及本机配置。不要打包 `.local` 凭据外发；保留当前源码与快照再回退。云端成套版本与回退步骤见部署与回滚方案；本轮没有回退演练。项目没有自动值守、生产高可用、多租户、权限分层或生产SLA承诺。
