# 风险与依赖

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

主要风险来自自然语言任务、旧协议兼容和状态继承之间的不一致。双模型独立提取可发现分歧，也可能同时漏掉最高、最早或短答用途；结构合法不代表理解正确。

|风险或依赖|实际影响|交接处理|
|---|---|---|
|第三轮语义和续问反例|此前42步通过不能覆盖新的自由问法|原问句入已知问题，状态为待分析|
|查询完成与任务完成不一致|列出48条并不回答“最高是哪条”|核验输出目标、排序和取首项|
|零结果缺字段说明|名称与编码意图可能不一致|核对包含操作和字段，不假报不支持|
|状态源并存|entity、草稿、业务任务、点选对象可能互相干扰|按代码阅读指南逐层追踪|
|在线模型服务|网络、限额、参数与供应方变化影响质量时延|保存实际模型标识与时间，不承诺固定响应|
|真实数据不在GitHub|仅克隆无法完成依赖快照的回归|提供文件清单，数据由用户另行安排|
|云端HTTP、演示账号和共享导入|未提供生产TLS、多租户及细粒度权限|明确POC范围，导入发布会影响全体访问者|
|Codex动态工具实验接口|安装版本变化可能影响App Server协议|只用于本机，版本升级需冒烟验证|
|旧Windows脚本及绝对路径|新Mac不保证所有历史回放脚本可直接运行|以macOS手册和离线入口为准|

没有生产并发、高可用、完整灾备或客户验收证据。凭据使用本机或官方入口配置，不进入聊天、源码或交付文档。
