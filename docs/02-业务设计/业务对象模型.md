# 业务对象模型

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

五类表分别描述现场目录、构型结构、设备分类、部件分类和观测记录。它们不是同一种“设备”，不能把行数相加，也不能认为相同短标识在不同树中指同一个对象。

|业务对象|原表与标识|含义|关键关系|
|---|---|---|---|
|PBS对象|pbs.csv 对象代码|现场位置、设备、部件或测点层级|同树父对象代码；测点与PBS按完整编码关联|
|构型对象|构型树.csv 对象代码|设备/部件结构与构型关系|父对象代码；所属部件类代码；类型与层级字段独立|
|设备类|设备类.csv 对象编码|设备分类字典|父对象编码；构型映射需精确记录核验|
|部件类|部件类.csv 对象编码|部件分类字典|构型或现场部件引用分类编码|
|测点记录|测量点数据分析.csv 来源文件与行号|某来源的一条观测、状态、单位和阈值|同测量点编码可以多来源多行，不覆盖为单条|

代码对象唯一键为(tree, code)，测点记录保留来源文件和行号。规范化对象字段与原CSV字段不是同一个字段：原记录完整保存在raw中，答案必须能回到具体原行。

PBS编码中的 & 片段只在已确认的关联规则内解析，再精确核验构型及类型；测点沿真实PBS父链找结构对象。构型父节点和设备类、所属部件类字段和部件类字典分别核验。未匹配关系保留已知事实及原因，不补造对象或名称。

例：MOHB01直接下级共52对象，其中51部件和1子设备；全部后代222对象，其中221部件。这是当前快照例子，不能推广为所有构型固定比例。当前数量见数据模型，具体查询需使用对应对象域和数据版本。
