# 数据模型设计

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

当前Store使用内存SQLite，保留原始CSV字符串、文件SHA256及行号。模型不生成SQL，所有执行路径使用注册字段与参数化条件。种子读取GB18030 CSV；上传导入支持UTF-8 BOM和GB18030，完整表头以backend/import_schema.json为准。

|实体|字段概要|键与用途|
|---|---|---|
|objects|tree、code、parent、name、level、class_code、source、line、raw|主键(tree,code)，四树对象与原始行JSON|
|ancestors|tree、child、ancestor、depth|主键(tree,child,ancestor)，真实父链的递归闭包|
|points|line、code、name、system、value、unit、status、switch、time、raw|line为内部记录键；point_refs映射来源文件和原始行|
|CSV dataset|kind、file、sha256、rows、seed|原数据包及来源身份，用于重建Store|
|导入快照JSON|id、created、version、counts、dataset|持久不可变数据；active.json指向当前快照|

数据库规范化字段level承载历史兼容展示值，类型和层级准确区分须读CATALOG对应的原字段。r11的type：构型对应“对象层级描述”，PBS对应“对象层级”；level维度另按目录映射，不能用层级编号代替类型。

上述是已登记快照的数量，五种对象含义不同，不相加作为设备数。原字段缺值、单位缺失、1970时间及未匹配关系保持原样。测点按完整编码关联PBS；同编码不同来源记录并列保留，不以编码为单行覆盖键。

导入对同树同码完全相同行去重，冲突行拒绝；父链环路及超过64层拒绝。缺少父目标或测点未匹配PBS给出警告，不编造关系。追加/替换和恢复均先预览再提交，预览15分钟过期并核对基准version；发布保存旧新快照后切换活动指针。所有浏览者共用当前Store，提交会清空活动查询会话。

全部CSV表头登记如下；名称、行数与值只能从授权原件核对，不从本表头清单推断数据内容。

### pbs 原始字段

`对象代码`、`父对象代码`、`对象描述中文`、`对象层级`、`所属重大设备`、`插入时间`、`最后更新时间`。

### config 原始字段

`对象代码`、`父对象代码`、`对象描述中文`、`对象层级`、`对象层级描述`、`是否叶子节点，否0， 是1`、`所属部件类代码`。

### equipment_class 原始字段

`对象编码`、`父对象编码`、`描述`、`层级`。

### part_class 原始字段

`对象编码`、`父对象编码`、`对象描述中文`、`对象层级`。

### points 原始字段

`测量点编码`、`源系统测点编码`、`源系统`、`测量点名称`、`测量值`、`预测值`、`变化速率`、`单位`、`状态`、`开关`、`测量时间`、`预测时间`、`估计时间`、`真实值报警阈值-低3`、`真实值报警阈值-低2`、`真实值报警阈值-低1`、`真实值报警阈值-高1`、`真实值报警阈值-高2`、`真实值报警阈值-高3`、`估计值报警阈值-低3`、`估计值报警阈值-低2`、`估计值报警阈值-低1`、`估计值报警阈值-高1`、`估计值报警阈值-高2`、`估计值报警阈值-高3`、`变化速率偏差报警阈值-低3`、`变化速率偏差报警阈值-低2`、`变化速率偏差报警阈值-低1`、`变化速率偏差报警阈值-高1`、`变化速率偏差报警阈值-高2`、`变化速率偏差报警阈值-高3`、`报警原因`。
