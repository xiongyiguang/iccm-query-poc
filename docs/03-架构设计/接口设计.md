# 接口设计

2026-10-09发布候选：本次仅发布DeepSeek普通版公共机制修复，活跃协议V32/V28/V25、业务请求V10/独立清单V13；Codex智能体保留已提交交接版本。发布状态和本轮实测以[普通版r12发布记录](../07-部署与运维/DeepSeek普通版r12发布记录-20261009.md)为准；下文旧日期的“未发布”及r11表述为历史事实，不代表本轮最终状态。

版本：V6｜2026-10-09｜用途：当前本地修复源码，未更新腾讯云或GitHub；非客户正式验收。


追加会话时序：每个在途请求有独立所有权；完成状态及续问签名后，先释放自己的标记再发送结果。迟到finally不得释放下一请求。数量越界的类型化业务约束由结果目标校验器产生，经独立提取接入传递；清楚提示1至100范围且不执行。网络、其他结构错误不改称业务拒绝。默认身份元数据投影只在逐项证明后参与全部未来任务状态比较；不能仅凭当前答案相同忽略new/update或丢弃其他分支。

2026-10-08追加本机优化：合法但缺数据的任务保存pending_business_request草稿及pending_tasks稳定编号；多任务只清除本次实际完成项，未执行或仍失败的分支继续保留。先前成功business_request与当前待补草稿分开；全部待补任务完成才提交整组，明确整组new不继承旧待补任务编号。HTTP、签名续问和前端采用同一状态语义。

PBS根对象范围内的测点是自身及全部后代的实际父链关联集合，走已实现带entity的专用路径；根标识不进入测点自身identity筛选。附加来源/状态/名称筛选独立保留；单个测点属性读取仍是单点定位。页面business_scope来自实际执行依据，删除无条件的“全部测点”标签。

日历日/月date_equals与精确对齐业务时区的半开区间按数学边界归一，不按条数猜测；时刻相等、微秒偏移、错上界和无效日期不合并。仅唯一实际原对象、单精确身份条件、身份属性及名码投影时，跨树objects定位与该实际树定位可规范为同一语义；多对象、列表、额外筛选及其他投影保持域差异。

2026-10-08公共机制扩展：业务请求V10与独立清单V13的result_goal仍有七个固定键；difference.direction支持null（有向减法）或absolute（绝对差），执行回执保存实际动作。两种差值均须operation=search；时间/数值排序与极值也须记录查询，不能从属性投影计算。selection={tree,code}在单一待答属性任务的闭合继续语句下由当前数据证明其属于当前候选范围；其他新问题仍走完整模型核验。差值成功响应可能total=0但带metrics、operands、evidence及completed回执，客户端不能据total判断为空结果。

当前API是同源Web POC协议，不是对外稳定产品API。以backend/app.py Handler为执行事实源。除登录外，POST需有效登录（云端启用时）、允许的Host/Origin及X-Demo-Token；Token从本次/api/meta取得，不能在文档中固定。

|方法与路径|输入概要|输出/副作用|
|---|---|---|
|GET /api/meta|当前鉴权会话|token、version、sources、counts、model、field_labels|
|GET /api/browse|tree、code/q、page|按真实层级浏览对象，默认页24项|
|GET /api/operations|tree、code；当前鉴权及允许Host|entity、version、operations：label/operation/enabled/reason；基于同一Store真实只读关系和监测资料|
|GET /api/objects|tree、q、parent|有界名称/编码搜索，最多100项|
|POST /api/query|session、question或intent、selection、version、trace|模型问答或明确引导操作；结果与context、continuation、计时|
|POST /api/context|session|清空既有对象上下文、对话及待确认单；不调用模型|
|POST /api/reset|session|删除指定活动会话，取消时使迟到响应失效|
|POST /api/resume|session、continuation、version|核验签名和数据版本后恢复有限状态，旧分页缓存不恢复|
|POST /api/page|session、result、page|已缓存完整结果的20行展示页|
|POST /api/evidence|session、result、page|20项原始行依据及总数|
|POST /api/confirm|session、review、tasks、version|旧确认协议兼容接口，一次性且绑定会话；r11新明确查询不生成确认单|
|POST /api/review/cancel|session、可选review|取消旧待确认单|
|GET /api/import/schema|当前鉴权会话|五类字段清单与快照历史|
|POST /api/import/preview|mode、files或restore|构建候选、数量和警告；不发布数据|
|POST /api/import/commit|preview|发布全局Store并清空会话，有写入副作用|
|POST /api/auth/login|username、password及有效Origin|云端Cookie，禁止记录请求明文|
|POST /api/auth/logout|有效Origin和Cookie|撤销登录并过期Cookie|

query响应关键字段：status、answer、records、columns、metrics、total、result、context、query_receipt（结果具备时）、business_scope/query_basis（适用时）、evidence/evidence_total、mode、version、continuation、server_ms、timings_ms。attributes结果还包含属性投影和覆盖度；batch包含独立items，每项有独立result编号。trace仅在请求明确为true时返回诊断。

计算响应的goal_receipt记录目标、完成状态及适用的完整集合数量；query_receipt包含同一result_goal，执行凭据绑定最终计划。新普通请求不能丢目标后当作默认列表放行。候选响应candidate_only=true，outcome.candidate_count是候选总量；total仅预览行数，count_computed=false，不代表已完成属性读取或业务计算。

status=ok也可能是合法零结果，需检查输出是否完成原问题。clarify表示未执行当前缺条件任务；not_found、missing等业务结果与系统错误分开。400为参数/执行校验失败，401登录失效，403来源/Token不符，409会话取消，422计划契约错误，503模型不可用，500未处理服务错误。模型错误不能当0条。

操作能力接口验证对象及当前版本；前端按版本和对象缓存、忽略迟到响应，网络失败可重试。无关系、无监测数据、无报警事件分别给出原因；不调用语言模型。

首屏records/evidence最多20项；total和业务metrics含义不同。服务端按完整集合统计，分页不会改变原范围。server_ms包含本轮服务端规划/查询时间，不包括浏览器渲染和人工补答时间。

接口详情和真实请求示例应从现有测试或浏览器请求核对，不复制历史设计的/query、/results/{id}草案作为当前API。Agent使用自己的/api/new、/api/ask和事件轮询协议，与此表的会话和Token不互通。
