# 安全与权限设计

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

当前系统的安全边界服务于脱敏POC，不代表生产安全验收。业务查询使用只读内存SQLite，禁止模型自由SQL和设备写回；数据导入是需要显式提交的独立写操作。

|边界|当前措施|限制|
|---|---|---|
|网络|Python只监听127.0.0.1；云端Nginx反代8899到18765|公网目前HTTP，无生产TLS结论|
|来源|允许Host/Origin、X-Demo-Token、CSP和无缓存头|Token不是企业身份系统|
|云端登录|PBKDF2-HMAC-SHA256、200000次迭代、8小时Cookie、错误频率限制|演示级账号，无细粒度角色/多租户|
|结果与历史|签名续问、版本核对、内存结果、请求取消身份检查|重启签名密钥变更，历史只能回看|
|模型|只发送必要脱敏问句、概念、目录和回执|在线模型会收到这些业务内容，不是完全离线|
|Agent工具|只读动态工具、禁用shell/file/web/apps及外部MCP|实验接口需随安装版本核验|
|导入|表头、大小、编码、冲突、环路、版本比较与快照留存|所有已登录访问者共用导入数据，无按角色隔离|
|凭据|环境变量或.local/和云端环境文件|不打印、不提交，不把哈希或密码加入交接文档|

公网密码、DeepSeek key、Codex登录状态及本地访问文件不随GitHub交接。复现trace和模型原始响应可能含脱敏业务内容，保持在本地证据目录，不直接公开发布。新增生产认证、权限或客户数据外发需另行明确范围。
