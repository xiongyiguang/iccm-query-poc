# 技术选型记录

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

|技术|实际用途|选择理由|维护限制|
|---|---|---|---|
|Python标准库|HTTP、CSV、JSON、线程、网络和密码哈希|减少POC安装依赖，易于查看执行边界|http.server不是生产应用服务器|
|SQLite内存库|四树对象、祖先、测点只读查询|参数化条件、实际父链索引、原行定位|重启重建，容量与并发未做生产验收|
|Decimal|数值比较和展示|避免浮点近似改变原始数值条件|非数值、缺单位和跨单位仍需拒绝或澄清|
|浏览器原生JS/CSS/HTML|对话、对象、弹窗、分页、历史|没有构建链、前端第三方运行依赖|复杂交互状态集中在app.js，需阅读事件关系|
|DeepSeek官方HTTP接口|常规语义主提取与独立清单|沿用现有提供方，不新增SDK|模型服务版本不可按本地二进制冻结，需记录实际响应标识|
|Codex App Server|本机独立智能体|沿用本机安装和登录，动态只读工具|Python3.11+需tomllib，工具协议为实验能力|
|Node.js|前端离线运行检查及浏览器测试脚本|只用于开发验证|部分浏览器脚本保留旧绝对路径，需先审阅|

普通后端无第三方Python业务依赖，仍依赖授权CSV和在线模型账户。Agent要求Python3.11或更高，常规代码交接也统一推荐Python3.11+。已有macOS启动器优先使用本机Codex配套Python，路径失效时回退可用解释器；团队环境不必复制用户的绝对运行时路径。

母版2.8.0是工程规范版本，不是应用版本。旧PowerShell脚本保留历史工程检查用途；macOS日常运行不依赖PowerShell。当前依赖和具体安装路径以团队自己的环境核验，不把本机版本当跨机器安装保证。
