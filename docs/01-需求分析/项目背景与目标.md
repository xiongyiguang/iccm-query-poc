# 项目背景与目标

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

设备关系和监测数据分布在PBS、构型树、设备类、部件类及测量点五类表中。业务人员需要从自然语言问题找到对象、解释分类关系、查询直接或全部下级、筛选报警及读取阈值，而不要求掌握表名、技术字段或SQL。

POC目标是验证“语言理解→受限计划→程序查证→结果与依据→连续追问”是否能完成实际任务。现阶段读取客户脱敏快照，界面展示导入版本和来源行；不是实时设备监控或故障决策系统。

|目标|可检查结果|当前边界|
|---|---|---|
|设备对象与分类关系|名称、编码、上下级及字典来源正确|不能按编码形状猜对象或用类别名称冒充实例|
|监测与报警问数|筛选条件、记录数、编码数、值与单位明确|无报警事件起止数据，无法计算持续时长|
|多轮交互|对象与条件正确继承、换题与补答不串线|第三轮仍存在短答和范围续接反例|
|直观且可追溯|答案、业务口径、分页和原始依据可查看|按钮可见不代表对任意对象均适用|
|质量与时延|简单≥90%、复杂≥70%、完整结果≤5秒为原目标|未在客户冻结验收集完成整体验收|

当前转入团队代码分析交接，第三轮问题暂缓修复。RAG、生产连接、设备控制、对客户数据自动修正、通用多租户平台均不在此次交接实现范围。
