# 用户角色与场景

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

|角色|使用目的|当前可用操作|边界|
|---|---|---|---|
|客户业务测试人员|查对象、关系、报警、值和阈值|问答、补充歧义、选择对象、分页和查看依据|不能执行设备控制或自动故障诊断|
|售前演示组织者|核对场景及讲解口径|独立会话、明确编码、展示来源和限制|不以固定推荐问题代替自由问法验证|
|数据开发分析团队|阅读源码、核对模型与执行契约|克隆仓库、离线测试、授权数据核对和后续复现|不随仓库获得客户原始数据、云账号或模型凭据|
|环境维护者|安装、模型配置、日志和发布维护|按运行手册配置；云端操作需当前授权|当前无企业角色权限划分|

代表场景包括PBS到设备构型/设备类、构型直接与全部下级、现场部件类别去重、测点筛选、单点属性及阈值、受限分组占比、多轮换对象及澄清续接。第三轮最高/最早、月份统计、两点差值和快捷功能反例单独登记，不假定已受支持。
