# 产品形态与研发策略

版本：V1｜整理日期：2026-10-08｜用途：当前工程交接；非客户正式验收。

产品形态是单入口Web问数POC。用户通过输入框、对象选择、查询口径和依据完成查询，不面对SQL编辑器。普通版与独立智能体是两个实验入口，而非同一产品的统一运行版本。

普通版采用结构化业务请求、字段目录、独立清单和确定性执行，适合分析语义与状态契约。独立智能体由Codex自主选择受限只读工具，工具执行仍复用现有数据层。两条链路需要分别评测，不根据少量成功场景判断任一链路普遍更好。

当前代码经历了原意图、槽位复核、类型化任务及兼容适配等迭代，保留了多套状态和路径。后续是否整合或重构，应由接手团队先画清实际调用和状态归属，再以原失败、留出问法及独立数据预期评价。此次交接不追加关键词特判、不新增模型层、不改旧测试预期。

正式产品化尚需明确用户权限、实时数据接口、观测历史、数据治理、并发、TLS、发布和恢复要求；这些不是当前实现的既有承诺。
