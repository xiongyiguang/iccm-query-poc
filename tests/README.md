# 普通版测试与回放入口

日期：2026-10-09。普通版默认离线测试是tests目录 `test_*.py`，在仓库根运行：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -p 'test_*.py'
node tests/test_frontend_runtime.cjs
```

Python套件核对身份、真实父链、条件、属性投影、统计、请求变更、会话、导入和错误边界；不少测试使用默认CSV与已知数量，不具备原始授权数据时不能据此宣称完整回归通过。套件会创建临时HTTP服务和目录，但不调用真实模型或改变既有腾讯云服务。交接基线534项、第三轮修复561项属于各自旧版本；前轮普通579/579、Agent共享44/44结果见公共机制扩展排查V2；当前增加任务状态、日/月等价和身份域证明，最终结果见V3。

`test_frontend_runtime.cjs`使用模拟DOM验证HTTP环境下页面初始化和会话生成，不是浏览器视觉验收。其他cjs文件包含真实页面、指定网址或Playwright依赖，不属于这一离线入口。

`replay_*.py`、`compare_*.py`、`run_acceptance.py`、`run_cloud_replay.py`等用于历次真实模型/指定服务对照。有些配置本机或云端目标、输出docs/.staging，也可能调用模型产生费用。执行前打开脚本核对URL、依赖、凭据来源、数据快照与问题集；不要对所有脚本做无差别批量运行。前轮第三轮原题及变体26/26、历史29/29和新增35/35真实回归已完成，仍不是全部开放问题或线上验收。

测试预期应从独立原始行/父链得出。记录完整会话、选定主体、代码/Prompt版本、模型实际标识、结果和时延；旧断言失败与有据勘误分开。原始回放输出属于本地证据，不随Git推送，工程结论在docs/06-测试与验收唯一源登记。

`test_goal_boundaries.py`新增18项日期精度、执行目标、精确算术、候选及可信点选边界方法，属于离线套件。`replay_goal_boundaries.py --url http://127.0.0.1:8782 --output-dir docs/.staging/新的证据目录`为35步真实模型回放，只允许本机地址，需当轮授权和原始CSV；输出目录必须不存在。预期从CSV读取，失败退出码非零。

`test_goal_state.py`验证缺数据与部分完成状态、可信点选来源、实际范围以及唯一身份域证明；`test_goal_boundaries.py`追加5项日/月精度与时区边界，原断言不变。`replay_goal_state.py`为20步真实状态链，`replay_goal_scope.py`为5步原PBS父链范围回放，均只接受显式本机URL与全新输出目录，需本轮模型授权。分页及签名恢复与CSV业务断言一起检查，不把HTTP200当成功。

`test_request_lifecycle.py`用事件控制真实HTTP的旧请求延迟清理和新请求在途，验证响应完成后续问可进入、旧finally不清掉新busy、第三请求仍受并发保护；不靠等待时间掩盖竞态。数量约束新增合法1/100、非法类型、0/101及主独立接入测试。最终离线及真实矩阵实际统计登记于公共机制扩展排查V3。

追加最终源码V32/V28/V25：普通605/605、Agent共享44/44；真实35/35边界、20/20状态、5/5范围、29/29历史、26/26第三轮及2/2严格数量反馈。共117步中91为ok、2为batch、15澄清、5候选、3缺数据、1能力说明，不能称117次成功查询。test_goal_state另保证无数量限制的排序与极值不被核验门禁当作等价。原35步refuse允许HTTP400/422，只证明阻止错误执行；数量反馈另用严格2步复核，不能以旧宽断言声称反馈正确。证据唯一入口公共机制扩展排查V3。

`replay_engine_comparison.py`是冻结117步的双引擎真实回放入口。执行前准备全新证据目录，其中包括cases.json、source-manifest.json和原输入hash；核对模型发送范围、数据版本及当次授权。可用 `--engine ordinary` 或 `--engine agent`分别运行，默认both同时创建两版独立服务。只启动自己持有的8784/8785临时进程，端口被占用即拒绝，不启停已有服务；组内顺序保持，Agent每18组之间重建自身实例以避免会话容量限制。已有结果文件禁止覆盖，模型调用有费用。程序正常退出仅代表完整回放，不代表业务全部符合。

本轮先普通后Agent的实际脚本、234个首次结果、固定判据与business-review-v2另存docs/.staging/engine-comparison-20261008/；等价复核不调用模型、不重跑题目、不改原始成绩。本轮普通117/117，Agent固定57/117、业务复核76/117，19步差异理由和41步业务问题见[普通版与Codex智能体对照测试V2](../docs/06-测试与验收/普通版与Codex智能体对照测试-20261008.md)。应用与Prompt冻结核对一致；不是同模型架构消融、盲测或腾讯云验收。
