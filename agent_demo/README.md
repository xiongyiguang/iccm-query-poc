# 本机Codex智能体演示

日期：2026-10-09；当前实现V12.1，本机未发布，冻结48+117范围内验证通过。通过官方本机Codex App Server实验接口调用10个固定只读工具，使用同一五份脱敏CSV及普通版数据执行器。独立监听127.0.0.1:8771，独立令牌、会话及缓存。

Mac双击 `启动智能体.command`，或从仓库根运行 `python3 agent_demo/server.py --port 8771`。Python需3.11+，Codex需已安装、已登录、可联网调用模型。默认gpt-6-sol/low；页面模型选项不证明账户可调用。重启本机入口才能加载新的Python模块。

|文件|阅读目的|
|---|---|
|runtime.py|官方运行时发现、模型线程、动态工具与只读隔离|
|server.py|会话、事件、一次补查、实际交付清单及只读分页接口|
|tools.py|10个工具、查询协议校验、真实任务目标历史、会话缓存与分页|
|request_protocol.py|有据直接查询任务、计算目标及独立PBS范围|
|relational_protocol.py|受限跨表任务、稳定编号增量、唯一角色引用、范围及缺失说明|
|protocol_diagnostics.py|同一公开Schema入口校验及字段路径|
|bindings.py|完整标识、逐处显式原表域及真实引用来源|
|answers.py|真实最终目录和独立结果交付；重复完全相同回执仅留最近一份|
|presentation.py / web/|中文业务标签、部分完成标志、缓存明细连续分页|
|knowledge.txt / query-guide.txt / completion-check.txt|知识V14、工具协议V11、完成检查V4|

关系入口直接复用普通V9确定性执行器，不调用DeepSeek、不生成自由SQL。现场与构型分别统计，按精确代码和实际父链关联；未知分类及缺失对象不借父类、不补零。每任务独立编号、更新保留未改条件，完整目录覆盖同主体试查，并保留不同主体的已完成结果。程序发布delivery_result_ids和必要结论说明，不以模型草稿补事实。

完整结果缓存在所属会话，页面每页20行；`POST /api/page`只翻缓存，不调用模型、不修改任务或追加问答。部分关联与资料不足直接显示，另一任务的表格和标题保留。Host、Origin、独立令牌、结果归属和页码继续校验。
